# 르방이 — 비주얼·게임필 설계 문서

전제: 무캐릭터(눈·표정 금지), 코지 톤, 현 셰이더 미학(베이지·크림·테라코타, 절차적 범프) 유지·확장. 시뮬레이션 코어는 순수 함수(결정 9)이므로 본 문서의 모든 비주얼 파라미터는 `simState → renderParams` 순수 매핑으로 기술한다.

## 0. 현 프로토타입 자산 판정 (유지 / 승격 / 교체)

| 자산 | 판정 | 비고 |
|---|---|---|
| 절차적 가우시안 범프(버텍스+프래그먼트) | **승격** | 하드코딩 4개 → uniform 배열화 (아래 엔지니어 노트) |
| 숨쉬기 스케일 (±4%, 3.5s) | **승격** | 진폭·주기를 상태 구동 uniform으로 |
| 터치 wobble (감쇠 0.9) | **유지+확장** | poke·롱프레스 추가 (§4) |
| 팔레트 5색 (#E8D9C4 / #F4EAD4 / #C4784A / #8A6A4A / #4A3220) | **유지** | 토큰 체계로 확장 (§6) |
| 탑다운 90° 카메라 | **교체** | 저각 틸트 직교로 (§1) |
| 토러스(병 테두리) | **재해석** | "고무줄 눈금 마커"로 전용 (§1) |
| 텍스처 0·전량 절차 셰이딩 | **유지** | 출시까지 텍스처 fetch 0 원칙 |

> **엔지니어 노트 (셰이더 함정)**: 현 코드의 범프 4개는 버텍스(k=18~24)와 프래그먼트(k=54~72)에 **의도적으로 다른 첨도로 이중 정의**되어 있다 — 지오메트리는 완만하게, 라이팅은 날카롭게. 범프를 파라미터화(기포·상태 변화)할 때 두 리스트를 반드시 동기 갱신해야 하며, 실수 방지를 위해 `uBumpPos[8]`(vec2), `uBumpAmp[8]`, 버텍스/프래그먼트 첨도 계수 상수 2개로 승격해 **한 소스에서 양쪽을 구동**할 것. 어긋나면 라이팅이 지오메트리에서 유리된다.

## 1. 씬 진화

### 1-1. 뷰 선택: **저각 틸트 직교 (탑다운 유지도 순수 측면도 아님)**

**결정: 직교 카메라를 수평선 위 약 55° 고도로 내린 3/4 부감 뷰.**

근거:
- §2에서 부피를 "병 눈금 대비 높이"로 매핑해야 한다. 순수 탑다운은 높이를 HUD 게이지로 추상화할 수밖에 없어 탈락 — 성장이 씬 밖으로 밀려난다.
- 순수 측면 뷰는 (a) 현 셰이더가 XZ 평면 기반이라 전면 재작성, (b) 반죽을 유리 너머로 봐야 해서 투과 렌더가 필수 — 모바일 three.js에서 시각오류(알파 소팅) 최다 발생 지점. "시각오류 0" 기준과 정면충돌.
- 55° 틸트는 윗면 축소율이 cos35°≈0.82라 **반죽 윗면(현 범프 셰이더의 주 무대)이 여전히 주인공**이면서, 병 측벽·눈금·반죽 높이가 같은 화면에 들어온다. 터치 레이캐스트(y=0 평면 교차)와 wobble도 수정 없이 동작한다.

시작값 (직교 유지):
```
camera.position.set(0, 8.0, 5.6)   // atan(8/5.6) ≈ 55° 고도
camera.lookAt(0, 0.6, 0)           // 병 몸통 중심
frustum viewH = 4.2 (세로 기준), 세로폰에서 병+헤드룸이 화면 55~65% 점유
```
숨쉬기·부풀기 헤드룸을 위해 병 위쪽 여백을 넉넉히. 값은 실기기에서 미세 튜닝.

### 1-2. 유리병

- 형태: 직벽 원통(반지름 0.92 — 기존 토러스 반경 계승, 높이 1.9, radial 48). 입구에 살짝 벌어진 립.
- **렌더 전략 (굴절 금지, 3패스 고정 순서)** — `transmission` 계열은 모바일에서 비용·아티팩트 모두 부적격:
  1. 유리 **뒷면** (`side: BackSide`, 커스텀 셰이더): 알파 0.06의 은은한 내벽 톤. `depthWrite: false`, `renderOrder: 1`
  2. **내용물** (반죽 본체 + hooch 층): 불투명, `renderOrder: 2`
  3. 유리 **앞면** (`side: FrontSide`): 프레넬 림 하이라이트만 — `alpha = 0.05 + 0.30 * pow(1 - dot(N, V), 3.0)`, 따뜻한 화이트 #FFF6E8. `depthWrite: false`, `renderOrder: 3`
  - renderOrder를 명시 고정하므로 알파 소팅 오류가 구조적으로 발생하지 않는다.
- **눈금**: 유리 앞면 셰이더에 절차적으로 — 월드 y 기준 0.25 간격의 가는 수평선(`smoothstep` 밴드, 잉크색 #8A6A4A 알파 0.25), 왼쪽 1/4 원호 구간에만. 텍스처·추가 지오메트리 0.
- **고무줄 마커 (기존 토러스 재활용)**: 실제 사워도우 관례 그대로 — 테라코타(#C4784A) 가는 토러스(튜브 반경 0.025)가 병 바깥을 감싸고, **마지막 밥준 시점의 반죽 높이**에 위치. 반죽이 그 위로 부풀면 성장이 한눈에 읽힌다. 밥주기 완료 시 현재 높이로 슬라이드(0.4s, easeOutCubic). 부피 정보의 정본 표시 장치.
- **천 덮개**: 리넨색(#EDE3CE) LatheGeometry 디스크, 가장자리가 살짝 늘어진 실루엣, 주름은 프래그먼트 노이즈 음영으로. 평상시엔 병 뒤 테이블에 접혀 있고(장식 소품), **휴면 상태에서만 병 위를 덮는다** — "재워뒀다"의 다이제틱 표현. 덮기/걷기 트윈 0.6s.

### 1-3. 배경·조명

- 배경: 단색 → **라디얼 그라디언트** (중심 #F2E6D3 → 가장자리 #E0CFB5). 풀스크린 셰이더 쿼드 1장 또는 CSS(캔버스 투명)로. 은은한 비네트가 병을 감싼다.
- 접지: 병 아래 **베이크드 소프트 섀도** — 라디얼 그라디언트 알파 평면 1장(#4A3220, 최대 알파 0.12). 실시간 섀도맵 금지(비용).
- 시간대 틴트: wall-clock 기반으로 배경·키라이트 색온도를 ±4%만 이동(아침 #FFE9C4 → 저녁 #FFDCA8). 실시간 다마고치(결정 1)와 정합하는 무비용 생명감.
- 조명: 현행 유지(키 디렉셔널 0xffe2b0 + 앰비언트) + 반대편에서 차가운 기미의 필 라이트 0.15 (형태 입체감). 섀도맵 0.

## 2. 상태 → 비주얼 매핑

### 2-1. 매핑 함수 계약

```ts
// 시뮬레이션 코어 출력 (순수)
type SimVisualState = {
  activity: number;   // 0~1 발효 활성도
  hunger: number;     // 0~1 배고픔
  sourness: number;   // 0~1 산미
  dormancy: number;   // 0~1 휴면 깊이
  fill: number;       // 반죽 높이, 고무줄 기준 1.0 (0.6~1.6)
  hooch: number;      // 0~1 부유액(회색 액체) 층
};
toRenderParams(s: SimVisualState): RenderParams  // 순수 함수, vitest 대상
```

### 2-2. Uniform 목록과 값 범위

| uniform | 타입 | 범위 | 기준값(현행) | 구동 소스 |
|---|---|---|---|---|
| `uColor` | vec3 | 아래 색 보간표 | #F4EAD4 | hunger·sourness·dormancy |
| `uBreatheAmp` | float | 0.004 ~ 0.055 | 0.04 | activity·dormancy |
| `uBreathePeriod` | float | 2.6 ~ 7.0 (s) | 3.5 | activity (활발할수록 짧게) |
| `uNoiseSpeed` | float | 0.1 ~ 1.6 | 1.0 (현 0.35/0.28 계수의 배율) | activity |
| `uBubbleDensity` | float | 0 ~ 1 | — | activity·hunger |
| `uBubbleScale` | float | 0.5 ~ 1.5 | — | activity (활발=크고 굵게) |
| `uSpecStr` | float | 0.1 ~ 1.2 | 1.0 (현 spec 계수 배율) | hunger·dormancy (마르면 매트) |
| `uCrust` | float | 0 ~ 1 | 0 | dormancy (표면 마른 껍질·미세 크랙 노이즈, spec 감쇠와 연동) |
| `uFillY` | float | 0.6 ~ 1.6 | 1.0 | fill — 반죽 y 스케일 |
| `uHoochAmt` | float | 0 ~ 1 | 0 | hooch — 별도 액체 층 메시의 두께·알파 |
| `uBumpPos[8]` / `uBumpAmp[8]` | vec2/float | — | 현 4개 좌표 계승 | 기포 생명주기 (§2-4) |
| `uWobble` / `uPoke*` | vec2 등 | — | 현행 | 입력 (§4) |
| `uTime` | float | — | — | `performance.now` 기반 (rAF 누적 금지 — 결정 1 정합) |

### 2-3. 상태별 프리셋 표

| 상태 | uColor | 숨(Amp / Period) | 기포(밀도/크기) | 표면 | uFillY 경향 | 비고 |
|---|---|---|---|---|---|---|
| **활발** (밥 직후 피크) | 크림 #F4EAD4 | 0.055 / 2.6s | 0.9 / 1.3 | 촉촉 spec 1.2 | 1.2→1.6 상승 | 고무줄 위로 부풀어 오름 |
| **정상** | #F1E6CE | 0.04 / 3.5s | 0.5 / 1.0 | 현행 | 1.0~1.2 | 현 프로토와 동일한 인상 |
| **배고픔** | 회끼 #DCD2C0 | 0.02 / 5.5s | 0.15 / 0.6 | 매트 spec 0.4 | 0.8로 꺼짐 | 숨이 느리고 얕아짐 |
| **시큼** | 어두운 황회 #CBBDA2 | 0.015 / 6.0s | 0.1 / 0.5 | 매트 + hooch | 0.7 | **hooch 층 등장** (아래) |
| **휴면** | 창백 #E4DCCC | 0.006 / 7.0s | 0 | uCrust 0.8, spec 0.15 | 0.65 | 거의 정지 + 천 덮개, 완전 정지는 금지(죽음 연상) |

- **hooch (부유액)**: 실제 방치된 르방에 생기는 회갈색 액체 층. 반죽 윗면 위 얇은 반투명 디스크 메시(#9C927F, 알파 0.35~0.6, 미세한 유동 노이즈). 배고픔·산미의 **무표정 다이제틱 신호** — 얼굴 없이도 "돌봐야 한다"가 즉시 읽히고, 부활 의식의 "따라내기" 연출 대상이 된다.
- 상태 사이는 프리셋의 이산 전환이 아니라 SimVisualState 연속값의 선형 혼합으로 계산 — 표는 앵커 포인트다.

### 2-4. 기포 시스템 (파티클 아님 — 셰이더 절차)

- 현 범프 기법을 그대로 기포에 전용: `uBumpPos[8]`에 기포 위치, `uBumpAmp[8]`에 생명주기 진폭. CPU에서 기포 수명 관리(스폰 간격 = `lerp(6s, 0.8s, uBubbleDensity)`), 셰이더는 배열만 읽는다.
- 기포 생명주기 (개당 2~4s): 부풀기(진폭 0→max, easeOutCubic) → 정점 유지 → **터짐**: 진폭이 80ms에 음수(-0.3max)로 꺼지며 프래그먼트에 링 하이라이트 1프레임대 잔상 → 소멸. 터질 때 사운드 §5.
- 정점 셰이더는 완만한 k, 프래그먼트는 날카로운 k — 현행 첨도 분리 규칙 그대로 계승 (§0 노트).

### 2-5. 전환 정책 (결정 1 필수 부속)

- **앱 오픈 시**: 오프라인 catch-up 결과 상태로 **즉시 스냅**. 몇 시간 치 변화를 애니메이션으로 재생하지 않는다 — "돌아와 보니 이렇게 되어 있었다"가 다마고치 문법.
- **라이브 중**: 모든 uniform은 목표값으로 2~4초 지수 lerp(`v += (target - v) * (1 - exp(-dt/τ))`, τ≈1.2s). 밥주기 직후 활성도 상승 곡선은 sim이 계산하고 비주얼은 따라만 간다.
- 기기 시계 조작으로 상태가 튀어도 위 스냅/lerp 규칙만 타므로 비주얼 크래시 경로 없음.

## 3. 액션 연출

공통 기법: 파티클은 **단일 InstancedMesh 공용 풀**(§7), 트윈은 자체 미니 트윈(이징 3종, §4), 나머지는 uniform ramp. 무캐릭터 원칙은 이펙트에도 적용 — **하트·별·반짝이 금지, 전부 다이제틱**(밀가루·물·김·기포)만.

### 3-1. 밥주기 (총 2.8s)

| 구간 | 연출 | 기법 |
|---|---|---|
| 0.0–0.6s | 밀가루 뿌림: 화면 위에서 흰 분진 낙하, 표면에 가루가 얇게 덮임 | 파티클 80개(작은 원 빌보드, 중력+회전, 착지 시 소멸) + `uFlourDust` 0→1 (프래그먼트 흰 노이즈 오버레이) |
| 0.5–1.2s | 물 붓기: 가는 물줄기 + 착수점 잔물결 | 세로 리본 메시 1개(스크롤 셰이더) + 버텍스 링 리플 + `uSpecStr` 상승 |
| 1.2–2.4s | 젓기: 반죽 표면이 소용돌이치며 가루·물이 섞여 사라짐, 색이 크림으로 리셋 | `uStir` 0→1: 버텍스 XZ 회전장(중심 강함), `uFlourDust`·hooch 감쇠, wobble 원형 1회전 |
| 2.4–2.8s | 정착: 살짝 눌렸다 복귀, 기포 2~3개 뽀글, **고무줄이 현재 높이로 슬라이드** | y스케일 damped spring + 기포 스폰 + 토러스 y 트윈 0.4s | 
| 2.8s | 햅틱 impactLight, 2음 사운드 (§5) | — |

도구(숟가락 등)는 그리지 않는다 — 손 없는 화면에 도구만 떠 있으면 어색하고, 반죽 스스로의 소용돌이가 더 담백하다.

### 3-2. 빵굽기(수확) 시퀀스 (총 5.5s, 중앙 카드 안에서)

| 구간 | 연출 | 기법 |
|---|---|---|
| 0.0–0.8s | 떼어내기: 반죽에서 작은 덩어리가 부풀며 분리, 본체 `uFillY` 소폭 감소 | 소형 blob 메시 스케일업 + 본체 uniform ramp |
| 0.8–1.6s | 덩어리가 화면 중앙으로 떠오르고 배경 딤(중앙 팝업 카드 등장) | 위치 트윈 easeInOutCubic + 백드롭 알파 0.25 |
| 1.6–4.6s | 굽기: 덩어리가 빵 실루엣으로 변형, 색이 크림→황금(#D9A05B)→크러스트(#A9713F)로 익음, 김 8개 상승, 카드 배경에 온기 글로우 | 지오메트리 morph(스케일 보간) + 색 lerp 셰이더 + 김 파티클(느린 상승·확산·페이드) |
| 4.6–5.5s | 완성: 빵이 컬렉션 카드에 담김, 해금 사운드 + notificationSuccess 햅틱 | 카드 wipe 채움 0.5s |

### 3-3. 부활 의식 (총 ~5s + 사용자 터치 개입, 신규 비용 거의 0 — 재사용 조립)

3단계를 사용자가 직접 수행하는 "의식"으로 — 유일하게 절차감을 주는 연출:

1. **윗물 따라내기** (터치 홀드 1.2s): 병이 8° 기울고(easeInOutSine) hooch 층이 흘러나가 사라짐. `uHoochAmt` 1→0.
2. **밥주기** — §3-1 연출 전체 재사용.
3. **지켜보기** (3.5s): 카메라가 12% 줌인(직교 frustum 축소 트윈)해 한 호흡을 함께 본다. 첫 기포 하나가 "뽁" 터지며 `uColor`가 2s에 걸쳐 크림으로 회복. 문구: "다시 숨쉬기 시작했어요". 햅틱 impactMedium 1회.

## 4. 게임필

### 4-1. 터치 반응 (현 wobble 확장)

- **탭**: 탭 지점에 국소 눌림 — `uPokePos`(vec2) + `uPokeAmt` 가우시안 덴트(깊이 0.06), damped spring 복귀 0.35s. 근처에서 기포 1~2개 유도 스폰. 눌림 큐 최대 3개, 초과 입력은 흡수(연타해도 소란스럽지 않게).
- **드래그**: 현 wobble 유지하되 입력 게인 0.12→0.09로 하향 — 출렁임을 반 박자 무겁게, 반죽의 점성이 느껴지게.
- **롱프레스** (0.8s+): 손가락 쪽 표면이 아주 천천히 0.03 부풀어 오름 — 눈 없이 "알아챈다"만 전달하는 생명감. 떼면 easeOut으로 가라앉음.

### 4-2. 햅틱 (Capacitor Haptics, 희소하게)

| 이벤트 | 햅틱 |
|---|---|
| 밥주기 완료 | impactLight ×1 |
| 레시피 해금·빵 완성 | notificationSuccess |
| 부활 성공 | impactMedium ×1 |
| 탭·기포 터짐·드래그 | **없음** (코지 톤 — 진동이 잦으면 소란) |

설정에서 끄기 가능, 저장 스키마에 포함.

### 4-3. 이징 (3종으로 통일 — 톤의 일관성)

| 용도 | 곡선 |
|---|---|
| 등장·성장·정착 | `cubic-bezier(0.22, 1, 0.36, 1)` (easeOutQuint 계열 — 빠르게 와서 길게 잦아듦) |
| 왕복·숨·기울임 | easeInOutSine |
| 탄성 복귀 (poke·젓기 후) | damped spring `e^(-5t)·cos(12t)` — 오버슈트 1회 이하 |

**금지**: 다회 진동 elastic, bounce — 다마고치식 촐랑거림은 이 게임의 톤이 아니다.

## 5. 사운드 (WebAudio 전량 합성, 에셋 0)

### 5-1. 인프라

- **첫 사용자 제스처에서** AudioContext 생성·resume (모바일 자동재생 정책). `visibilitychange` / Capacitor `appStateChange`에서 `suspend()` — §7 배터리 가드와 짝.
- 마스터 GainNode(0.25) → 로우패스 3kHz(전체를 둥글게) → destination. 리버브 금지(비용·톤 모두).
- 음소거 토글: 저장 스키마 `settings.muted: boolean`. UI는 르방 화면 구석의 작은 아이콘.

### 5-2. 사운드 스펙

| 사운드 | 합성 스펙 | 길이 |
|---|---|---|
| 기포 뽀글 | sine, 400→700Hz 글라이드 40ms, gain env A5ms/D80ms, 피치 ±15% 랜덤, LPF 1.2kHz. 동시 최대 3성 | 0.12s |
| 밀가루 사락 | pink noise, high-shelf -12dB, gain 아주 작게 페이드 | 0.5s |
| 물 붓기 | white noise → bandpass 600→900Hz 스윕, gain에 8Hz LFO 미세 흔들림 | 0.6s |
| 젓기 | brown noise → bandpass 200–400Hz, StereoPanner를 sin으로 원형 패닝 | 1.2s |
| 밥주기 완료 | triangle 2음 C5→E5, 각 decay 짧게, 간격 120ms — 마림바 느낌 | 0.4s |
| 해금·빵 완성 | triangle 3음 G4–C5–E5 간격 90ms, 끝음에 5도 배음 살짝. 유일한 "보상" 사운드 | 0.5s |
| 부활 성공 | 기포 뽀글 1회 + 밥주기 2음 재사용 | 0.5s |
| 휴면 진입 | **무음** — 침묵이 표현 | — |

- **레시피 카드**: 2열 그리드, `--bg-soft` radius 16. 카드 상단은 빵 실루엣 영역 — 해금 시 컬러 일러스트(CSS/SVG, 크러스트 팔레트), 미해금은 `--ink-faint` 20% 실루엣 + 자물쇠 아이콘 대신 문구 "성숙도 3이 되면 열려요". 해금 순간 크림→컬러 wipe 0.5s.
