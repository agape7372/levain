# 르방이 — 비주얼·게임필 (씬·uniform 정본)

> **정본 선언**: 씬 구성·uniform·연출·UI 룩은 이 문서가 정본.
> 게임 규칙·수치는 [GDD.md](GDD.md), 코드 계약은 [ARCHITECTURE.md](ARCHITECTURE.md).
> 원칙: 무캐릭터(눈·표정·하트·별·반짝이 금지 — 이펙트도 전부 다이제틱: 밀가루·물·김·기포),
> 코지 톤, 현 셰이더 미학(베이지·크림·테라코타·절차 범프) 유지·확장, 텍스처 fetch 0.

## 0. 프로토타입 자산 판정

| 자산 | 판정 | 비고 |
|---|---|---|
| 절차적 가우시안 범프(버텍스+프래그먼트) | **승격** | 하드코딩 4개 → uniform 배열 8개 (§2) |
| 숨쉬기 스케일(±4%, 3.5s) | **승격** | 진폭·주기를 상태 구동 uniform으로 |
| 터치 wobble(감쇠 0.9) | **유지+확장** | poke·롱프레스 추가 (§5) |
| 팔레트 5색 | **유지** | 토큰 11종으로 확장 (§7) |
| 탑다운 90° 카메라 | **교체** | 55° 틸트 (§1) |
| 토러스(병 테두리) | **폐기** | 고무줄 눈금 마커 제거됨(사용자 확정 2026-08-23) — 상세 §1-2 (개정 2026-08-24: 고무줄 마커 제거 반영) |

> **셰이더 함정 (계승 규칙)**: 현 범프 4개는 버텍스(k=18~24 완만)와 프래그먼트(k=54~72 날카로움)에
> **의도적으로 다른 첨도로 이중 정의** — 지오메트리는 완만하게, 라이팅은 날카롭게.
> 파라미터화할 때 `uBumpPos[8]`(vec2)·`uBumpAmp[8]`(float) **단일 uniform 배열을 양쪽 셰이더가 공유**하고
> 첨도 계수만 상수 2개로 분리한다 — 한 소스 구동이라 리스트 드리프트가 구조적으로 불가능.
>
> **v1.1 개정**: 레거시 함몰 4개(음수 진폭 −0.4, "라떼아트/금속 바람개비" 4엽 얼룩의 원인)는 폐기 —
> 8슬롯 전부 동적 기포(양수 돔)로 통합(§2). 휴지 실루엣은 고정 혹 대신 시간 정지 2옥타브 FBM이 대체.
> 프래그먼트 첨도 계수는 버텍스 × 3 → **× 1.6**으로 완화 — 라이팅-지오메트리 괴리("데칼감") 축소.

## 1. 씬

### 1-1. 카메라: 직교 55° 틸트 3/4 부감

```
camera.position.set(0, 8.0, 5.6)   // atan(8/5.6) ≈ 55° 고도
camera.lookAt(0, 0.8, 0)           // 병 몸통 중심보다 살짝 위 — 상단 HUD 헤드룸 확보 (개정 2026-08-24: 반유동체 개편 — 코드 실값 SceneHost.ts LOOK_Y 반영)
frustum viewH = 5.4                // 세로폰에서 병+헤드룸 55~65% 점유. 실기기 미세 튜닝 (개정 2026-08-24: 반유동체 개편 — 코드 실값 SceneHost.ts VIEW_H 반영)
```

근거: 부피=성장을 "병 눈금 대비 높이"로 화면 안에서 보여야 게임이 성립(탑다운 탈락).

주 무대)이 여전히 주인공이면서 병 측벽·높이가 함께 보이고, y=0 평면 레이캐스트도 무수정 동작.

## 2. 기포 시스템 (파티클 아님 — 셰이더 절차)

- `uBumpPos[8]/uBumpAmp[8]` 공유 배열을 기포에 전용. CPU에서 생명주기만 관리
  (스폰 간격 = `lerp(6s, 0.8s, uBubbleDensity)`), 셰이더는 배열만 읽는다.
- 기포 생명주기(개당 2~4s): 부풀기(0→max, easeOut) → 정점 유지 → **터짐**: 80ms에 진폭 **−0.12max**로
  얕게 꺼지고, 프래그먼트 **팝 링 하이라이트**(`q·e^-q` 커널 — 음수 진폭 슬롯만)가 밝은 링 잔상을
  그린다 → 소멸. 터질 때 뽀글 사운드(§6).
  (개정 2026-08-24: 함몰 −0.3 → −0.12 + 링 실장 — 어두운 원형 함몰 회피, 확장기획 §4-2b 근거)
- **동시 가시 상한 4개** — active 기포가 4개면 스폰 스킵 (밀집 클러스터 회피, 목표 2~4개 §4-1).
- **8슬롯 전부 동적 기포(양수 돔)** — 레거시 함몰 4개(음수 진폭)는 폐기. 휴지 실루엣은 고정 혹 대신
  시간 정지 2옥타브 FBM(`fbm(p.xz·1.8 + 상수시드)·0.05`)이 대체 — 비대칭 유기 블롭.
- **agitation**(드래그 속도 0~1, `bubbles.update`에 전달): 젓는 동안 스폰 간격 ÷3·수명 ÷2 —
  부상·팝 가속. 손을 떼면 즉시 원복(누적 없음).

불변, 어깨(45°)만 최대 1.297배 커진다. 소프트 니 반경 클램프(0.86~1.06)·반경 상한 0.69(`uRXZMax`)·
메니스커스 테·용기 접촉 그늘은 프래그먼트가 그린다.

### 3-4. 전환 정책

- **앱 오픈**: catch-up 결과로 즉시 스냅 — 경과를 재생하지 않는다(다마고치 문법).

## 5. 게임필

### 제스처 (input.ts FSM)

```
down ─ 이동<8px & <250ms 내 up → poke
     ─ 홀드 0.8s+               → 롱프레스
     ─ 이동≥8px ─ 반죽 위 시작 + 느린 끌기(<1.6px/ms) → grab(당기기, 확장기획 §4-2)
                ├ 배경 시작 + 수평 우세 + 전환 가능    → swipe(르방 전환, §5-5)
                └ 그 외(빠른 문지르기·반죽 밖 시작)      → stir(젓기, §4-1)
```
(개정 2026-08-24: 드래그 3채널 — 한 포인터 세션의 소유권은 중간에 안 바뀐다.)

| 제스처 | 트리거 | 반응 |
|---|---|---|
| **탭(poke)** | 이동<8px & <250ms 내 up | 탭 지점 가우시안 덴트(깊이 0.06, `uPokePos/uPokeAmt`) + 고체는 damped spring, 액체는 지수 완화 τ=mix(0.45,1.8,liquidity) + 커널 확산(넓어지며 얕아짐 = 아묾)(개정 2026-08-24: 반유동체 개편) + 근처 기포 1~2개 유도. 눌림 큐 최대 3 |
| **롱프레스** | 홀드 0.8s+ | 손가락 쪽 표면이 아주 천천히 0.03 부풂 — 눈 없이 "알아챈다"만. 떼면 easeOut |
| **grab(당기기)** | 반죽 위 down + 느린 드래그 | anchor 기준 **변위 추종**(`uGrabPos/uGrabDisp`) — 잡고 멈춰도 유지. 2시간척도 SLS: elastic(τ0.07s) + creep(0.7s+부터 잔류 축적). **놓기 = pointerup**. 릴리즈 시상수 분리: 리프트 τ0.35(중력 먼저) → 주름 τ0.25(`uGrabWrinkle`) → 커널 퍼짐(합류) → creep τ1.2(측방 마지막). elastic 복귀는 ζ≈0.95·ω5.5(오버슈트 ≤5%). necking(det=1) + 윈도우페인 + 겹 가닥. 상태 물성 3종(grabMax·creepGain·ζ)은 RenderParams. **확정 수치(사용자 실기기, 2026-08-24 저녁): 리프트 1.6 · 커널 k 1.6 · ω 5.5 · grabMax 피크 0.60** — GRAB_DEFAULTS·grabMax 매핑이 정본. 시뮬 효과 0 |
| **stir(젓기)** | 이동≥8px (grab 조건 밖) | 손가락 추종 시어장(`uStirPos/uStirVec`) + 끈적한 실(`uTrailPos[4]`, 개정 2026-08-24: 표기 정정), 놓으면(80ms 입력 정지) damped spring 복귀. 전신 wobble은 **stirVec(속도)을 목표로 한 감쇠 진동자**(슬로싱 — 아래 이징 예외) — 손가락 절대좌표 오프셋 폐기(개정 2026-08-24). 시뮬 효과 0 유지(GDD §5) |
| **swipe(르방 전환)** | 배경(항아리 밖) down + 수평 우세 드래그 | 후보 판정은 8px 시점의 \|dx\|>\|dy\|, **확정은 up에서 누적 \|dx\|≥48px & \|dx\|>\|dy\|×1.5**(8px 시점의 비는 터치 노이즈). 왼쪽으로 끌면 다음(+1)·오른쪽이면 이전(−1) — 칩 ‹ › 와 같은 순서·같은 경로(`api.switchStarter`). 전환은 컷(즉시 스냅·반점 시드 재설정). 차단: 르방 1마리·모달 열림·쇼케이스·연출 중(`SceneHost.canSwipe`). 확정 실패 시 아무 일도 없다(반죽 무접촉 — 레이캐스트도 생략). 시뮬 효과 0 (신규 2026-08-24) |
| **플릭(천 덮개)** | 위로 스와이프(속도 임계), 탭도 가능 | 덮개 걷기 0.6s `cubic-bezier(0.22,1,0.36,1)` — 콜드 스타트·hidden 30분+ 복귀 시에만 표시(§4-5) |

- 레이캐스트 평면은 **반죽 윗면(fill) 연동** — 고정 y=0.55 폐기, 손끝 = 눌리는 지점(개정 2026-08-24).
- **이징**: 등장·성장 `cubic-bezier(0.22, 1, 0.36, 1)` / 왕복·숨 easeInOutSine /
  탄성 복귀 damped spring `e^(−5t)·cos(12t)` (오버슈트 1회 이하). **elastic 다회 진동·bounce 금지.**
  단 **grab 복귀만 임계감쇠 근처**(위 표) — "고무줄 튕김"이 아니라 반죽의 되돌아옴.
  **예외 — 전신 슬로싱(`uWobble`)은 감쇠 진동자 1.5Hz·ζ=0.62−0.50·**fluidity**로 다회 출렁인다(액체 문법 — 개정 2026-08-25: 구 liquidity 구동 시 갓 밥준 ζ가 0.18이라 물처럼 5~6회 출렁였다).
  국소 변형(poke·stir·grab)의 다회 진동 금지는 유지.** (개정 2026-08-24: 반유동체 개편)
- 튜닝 하네스: `motionlab.html` (dev 전용, URL 파라미터 전체 상태 — breadlab 패턴).
  완료 판정은 확장기획 §4-1 목표 장면의 실기기 촬영 비교.
- **햅틱(희소)**: 밥 완료 impactLight / 해금·빵 notificationSuccess / 부활 impactMedium.
  **젓기(stir) 세션(down~up)당 최대 1회**(첫 기포 팝에 impactLight, 이후 무진동) — 연속 팝마다 울리면 소란스럽다.
  탭·기포·롱프레스·덮개 걷기 = 무진동. 설정에서 끄기 가능.

| squelch(젓기) | 밴드패스 300~900Hz 노이즈 루프(Q·게인 = 드래그 속도 추종) + 방향 반전 시 sine 180Hz 드롭 트랜지언트. API `sfxStirStart/sfxStirUpdate(speed)/sfxStirEnd` | 젓는 동안 지속 |
| 사락(천 덮개) | 하이패스 노이즈 버스트 | 0.25s |

부활 성공 = 뽀글 1회 + 밥 2음 재사용. **휴면 진입 = 무음 — 침묵이 표현.** 나머지 사운드(물 등)는 v2.

### 7-3. 타임라인과 폐기된 고무줄 마커·눈금(§1-2)의 무관함

`.hud-timeline`은 §1-2에서 폐기된 병 눈금·고무줄 마커의 부활이 아니다 — 겹치는 시각 문법이 하나도 없다:

| | 고무줄 마커·눈금(폐기, §1-2) | 발효 타임라인(신규, §7-2) |
|---|---|---|
| 축 | 세로 — 병 속 부피 | **가로 — 시간** |
| 위치 | 병 위(3D 씬) | 텍스트 스택 안(HUD, sub 문장 아래) |
| 채움 | 채워서 진행률을 말함(게이지 은유) | **채우지 않음** — 점 하나만 |
| 눈금 | 있음(병 목 표식) | **0개** |
| 숫자 | 없음(그래서 "정본이 아니다"로 폐기됨) | **0개**(같은 정보를 sub 문장이 말로 이미 전달) |

**채우지 않는다는 결정이 핵심이다** — 진행률을 칠하면 "지금 얼마나 찼나"라는 게이지 은유가 성립하고,
그건 §1-2가 "부피 정보는 도우 fill 표현 + 관찰 카드가 담당"으로 이미 정리해 둔 영역을 다시 침범한다.
타임라인은 부피를 말하지 않는다 — **"지금이 하루 리듬의 어디쯤인가"** 하나만 점으로 찍는다.
