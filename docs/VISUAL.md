# 르방이 — 비주얼·게임필 (씬·uniform 정본)

> **정본 선언**: 씬 구성·uniform·연출·UI 룩은 이 문서가 정본.
> 게임 규칙·수치는 [GDD.md](GDD.md), 코드 계약은 [ARCHITECTURE.md](ARCHITECTURE.md).
> 원칙: 무캐릭터(눈·표정·하트·별·반짝이 금지 — 이펙트도 전부 다이제틱: 밀가루·물·김·기포),
> 코지 톤, 현 셰이더 미학(베이지·크림·테라코타·절차 범프) 유지·확장, 텍스처 fetch 0.

## 0. 프로토타입 자산 판정

| 자산 | 판정 | 비고 |
|---|---|---|
| 절차적 가우시안 범프(버텍스+프래그먼트) | **승격** | 하드코딩 4개 → uniform 배열 8개 (§2) |
| 숨쉬기 스케일(±4%, 3.5s) | **승격** | 진폭·주기를 상태 구동 uniform으로 |
| 터치 wobble(감쇠 0.9) | **유지+확장** | poke·롱프레스 추가 (§5) |
| 팔레트 5색 | **유지** | 토큰 11종으로 확장 (§7) |
| 탑다운 90° 카메라 | **교체** | 55° 틸트 (§1) |
| 토러스(병 테두리) | **재해석** | 고무줄 눈금 마커로 전용 (§1) |

> **셰이더 함정 (계승 규칙)**: 현 범프 4개는 버텍스(k=18~24 완만)와 프래그먼트(k=54~72 날카로움)에
> **의도적으로 다른 첨도로 이중 정의** — 지오메트리는 완만하게, 라이팅은 날카롭게.
> 파라미터화할 때 `uBumpPos[8]`(vec2)·`uBumpAmp[8]`(float) **단일 uniform 배열을 양쪽 셰이더가 공유**하고
> 첨도 계수만 상수 2개로 분리한다 — 한 소스 구동이라 리스트 드리프트가 구조적으로 불가능.

## 1. 씬

### 1-1. 카메라: 직교 55° 틸트 3/4 부감

```
camera.position.set(0, 8.0, 5.6)   // atan(8/5.6) ≈ 55° 고도
camera.lookAt(0, 0.6, 0)           // 병 몸통 중심
frustum viewH = 4.2                // 세로폰에서 병+헤드룸 55~65% 점유. 실기기 미세 튜닝
```

근거: 부피=성장을 "병 눈금 대비 높이"로 화면 안에서 보여야 게임이 성립(탑다운 탈락).
순수 측면 뷰는 유리 투과 렌더 필수 → 모바일 알파 소팅 지옥(탈락). 55°는 반죽 윗면(현 셰이더의
주 무대)이 여전히 주인공이면서 병 측벽·높이가 함께 보이고, y=0 평면 레이캐스트도 무수정 동작.

### 1-2. 유리병 — 3패스 고정 renderOrder (굴절·transmission 금지)

직벽 원통(반지름 0.92 — 기존 토러스 반경 계승, 높이 1.9, radial 48), 입구 살짝 벌어진 립.

1. 유리 **뒷면**(`side: BackSide`): 알파 0.06 내벽 톤. `depthWrite:false`, `renderOrder:1`
2. **내용물**(반죽+hooch): 불투명, `renderOrder:2`
3. 유리 **앞면**(`side: FrontSide`): 프레넬 림만 — `alpha = 0.05 + 0.30·pow(1−dot(N,V), 3.0)`,
   따뜻한 화이트 #FFF6E8. `depthWrite:false`, `renderOrder:3`

renderOrder 명시 고정 → 알파 소팅 오류 구조적 차단.
**눈금**: 앞면 셰이더 절차 생성 — 월드 y 0.25 간격 수평선(smoothstep 밴드, #8A6A4A 알파 0.25), 왼쪽 1/4 원호만.
**고무줄 마커**: 테라코타(#C4784A) 가는 토러스(튜브 0.025)가 병 바깥, **마지막 밥 시점 반죽 높이**에.
반죽이 그 위로 부풀면 성장이 한눈에 읽힘 — 부피 정보의 정본 표시 장치. 밥 완료 시 현재 높이로 슬라이드(0.4s easeOut).

### 1-3. 배경·조명

- 배경: 라디얼 그라디언트(중심 #F2E6D3 → 가장자리 #E0CFB5) — CSS(캔버스 투명) 또는 셰이더 쿼드 1장.
- 접지: 병 아래 베이크드 소프트 섀도 — 라디얼 알파 평면 1장(#4A3220, max 알파 0.12). 실시간 섀도맵 금지.
- 조명: 현행(키 0xffe2b0 1.4 + 앰비언트 0xfff0dc 0.55) + 반대편 차가운 필 라이트 0.15.

## 2. 기포 시스템 (파티클 아님 — 셰이더 절차)

- `uBumpPos[8]/uBumpAmp[8]` 공유 배열을 기포에 전용. CPU에서 생명주기만 관리
  (스폰 간격 = `lerp(6s, 0.8s, uBubbleDensity)`), 셰이더는 배열만 읽는다.
- 기포 생명주기(개당 2~4s): 부풀기(0→max, easeOut) → 정점 유지 → **터짐**: 80ms에 진폭 −0.3max로
  꺼지며 프래그먼트 링 하이라이트 잔상 1프레임대 → 소멸. 터질 때 뽀글 사운드(§6).
- 상시 슬롯 4개는 반죽 기본 혹(현행 좌표 계승), 나머지 4개가 동적 기포.

### 3-1. 계약 (ARCHITECTURE §4의 체인)

`toRenderParams(snap: Snapshot): RenderParams` — 순수, vitest 대상. 입력은 GDD Snapshot

### 3-3. 상태 앵커 표

| 상태 | uColor | 숨(Amp/Period) | 기포(밀도/크기) | 표면 | uFillY | 비고 |
|---|---|---|---|---|---|---|
| **활발**(피크) | 크림 #F4EAD4 | 0.055 / 2.6s | 0.9 / 1.3 | 촉촉 spec 1.2 | 1.2→1.6 | 고무줄 위로 부풂 |
| **정상** | #F1E6CE | 0.04 / 3.5s | 0.5 / 1.0 | 현행 | 1.0~1.2 | 프로토와 동일 인상 |
| **배고픔** | 회끼 #DCD2C0 | 0.02 / 5.5s | 0.15 / 0.6 | 매트 0.4 | 0.8 | 숨이 느리고 얕음 |
| **시큼** | 황회 #CBBDA2 | 0.015 / 6.0s | 0.1 / 0.5 | 매트+hooch | 0.7 | **hooch 층 등장** |
| **휴면** | 창백 #E4DCCC | 0.006 / 7.0s | 0 | uCrust 0.8, spec 0.15 | 0.65 | 거의 정지 — 완전 정지 금지(죽음 연상) |

**hooch(부유액)**: 실제 방치 르방의 회갈 액체층. 반죽 윗면 위 얇은 반투명 디스크(#9C927F, 알파 0.35~0.6,
미세 유동 노이즈). 얼굴 없이 "돌봐야 한다"가 즉시 읽히는 무표정 다이제틱 신호 + 부활 "따라내기" 연출 대상.

### 3-4. 전환 정책

- **앱 오픈**: catch-up 결과로 즉시 스냅 — 경과를 재생하지 않는다(다마고치 문법).
- **라이브**: 전 uniform 지수 lerp(τ≈1.2s). 밥 직후 상승 곡선은 sim이 계산, 비주얼은 따라만 간다.
- 시계 조작으로 상태가 튀어도 스냅/lerp 규칙만 타므로 비주얼 크래시 경로 없음.

## 4. 액션 연출 (도구를 그리지 않는다 — 반죽 스스로의 움직임이 더 담백)

### 4-1. 밥주기 (2.8s)

| 구간 | 연출 | 기법 |
|---|---|---|
| 0.0–0.6s | 밀가루 낙하, 표면에 얇게 덮임 | 파티클 80(빌보드, 중력) + `uFlourDust` 0→1 |
| 0.5–1.2s | 물기 — 표면 광 상승 | `uSpecStr` 램프 (물 리본 메시는 컷 — 사운드 없이 광으로만) |
| 1.2–2.4s | 젓기 소용돌이, 가루·hooch 소멸, 색 크림 리셋 | `uStir` 0→1 (버텍스 XZ 회전장) + wobble 원형 1회전 |
| 2.4–2.8s | 정착 — 눌렸다 복귀, 기포 2~3개, **고무줄 슬라이드** | y damped spring + 토러스 y 트윈 0.4s |
| 완료 | 햅틱 impactLight + 2음 사운드 | |

### 4-2. 빵굽기 (v1 = 카드 리절트로 단순화 — 3D 시퀀스는 v2 백로그)

> **v1 구현 노트**: 아래 5.5s 3D 시퀀스(떼기→morph→김)는 설계 원안이며, v1은 confirm 모달 →
> 결과 카드(breadArt+등급)로 단순화했다. 판정 커밋 규칙(pendingBake)은 동일하게 구현됨.

떼기(blob 분리, 본체 uFillY 감소 0.8s) → 중앙 부상+배경 딤(0.8s) →
굽기: 빵 실루엣 morph + 색 크림→황금 #D9A05B→크러스트 #A9713F + 김 파티클 8(3s) →
도감 카드 wipe 채움 + 해금 사운드 + notificationSuccess(0.9s).
**판정 커밋은 시퀀스 시작 시**(GDD §6-2) — 연출은 재생일 뿐.

### 4-3. 부활 의식 (2세션에 분배 — GDD §3-7)

- 1회차 급여: **윗물 따라내기**(터치 홀드 1.2s — 병 8° 기울며 uHoochAmt 1→0) → 밥주기 연출 재사용.
- 2회차 급여: 밥주기 → **지켜보기**(3.5s): 카메라 12% 줌인, 첫 기포 "뽁", uColor 2s 크림 회복,
  "다시 숨쉬기 시작했어요" + impactMedium.

## 5. 게임필

- **탭(poke)**: 탭 지점 가우시안 덴트(깊이 0.06, `uPokePos/uPokeAmt`) + damped spring 복귀 0.35s +
  근처 기포 1~2개 유도. 눌림 큐 최대 3 — 연타 소란 방지.
- **드래그**: 현 wobble, 입력 게인 0.12→**0.09** — 반 박자 무겁게, 점성이 느껴지게.
- **롱프레스**(0.8s+): 손가락 쪽 표면이 아주 천천히 0.03 부풂 — 눈 없이 "알아챈다"만. 떼면 easeOut.
- **이징 3종 고정**: 등장·성장 `cubic-bezier(0.22, 1, 0.36, 1)` / 왕복·숨 easeInOutSine /
  탄성 복귀 damped spring `e^(−5t)·cos(12t)` (오버슈트 1회 이하). **elastic 다회 진동·bounce 금지.**
- **햅틱(희소)**: 밥 완료 impactLight / 해금·빵 notificationSuccess / 부활 impactMedium.
  탭·기포·드래그 = 무진동. 설정에서 끄기 가능.

## 6. 사운드 (WebAudio 전량 합성, 에셋 0 — v1 3종)

인프라: 첫 사용자 제스처에서 AudioContext 생성·resume(모바일 정책). hidden/pause 시 suspend.
마스터 GainNode(0.25) → LPF 3kHz → destination. 리버브 금지. 음소거 = `settings.muted`.

| 사운드 | 스펙 | 길이 |
|---|---|---|
| 기포 뽀글 | sine 400→700Hz 글라이드 40ms, A5ms/D80ms, 피치 ±15% 랜덤, 동시 최대 3성 | 0.12s |
| 밥 완료 | triangle 2음 C5→E5, 짧은 decay, 간격 120ms — 마림바 | 0.4s |
| 해금·빵 완성 | triangle 3음 G4–C5–E5 간격 90ms, 끝음 5도 배음 | 0.5s |

부활 성공 = 뽀글 1회 + 밥 2음 재사용. **휴면 진입 = 무음 — 침묵이 표현.** 나머지 5종(사락·물·젓기 등)은 v2.
