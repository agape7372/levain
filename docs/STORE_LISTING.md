  참여 선택 테스터 **12명 이상**이 **연속 14일** 유지된 뒤에야 대시보드에서 프로덕션 신청.
- 조직 계정, 또는 2023-11-13 이전 개인 계정은 이 12명 규칙 면제.

내부테스트부터 올리고, 공개가 목표면 바로 이어서 비공개 트랙을 연다.

## 콘솔에서 하는 순서

1. [play.google.com/console](https://play.google.com/console) → 개발자 계정 (없으면 $25·신원 확인)
2. 앱 만들기 → 이름 르방이 · 게임 · 무료
3. 대시보드 체크리스트를 위에서부터:
   스토어 등록정보 → 앱 콘텐츠(위 답) → 콘텐츠 등급 → Data Safety
4. 테스트 및 출시 → 내부 테스트 → 국가 한국 → 서명 AAB 업로드
5. 테스터 이메일 추가 → 선택 URL을 테스터에게 전달
   (Play 스토어 앱이 **그 구글 계정**으로 로그인돼 있어야 함)

## 남은 사용자 작업

1. Play Console 개발자 계정 준비·로그인

4. 내부테스트 테스터 이메일
5. 공개가 목표면 비공개 테스트 12명 모집
