# 르방이 — 수동 QA 체크리스트 (릴리스 게이트)

전제: vitest 전 suite green. 아래는 실기기/에뮬 수동 검증. 판정이 애매한 항목은 본 세션 재확인.

## A. 시간·시뮬레이션

- [ ] 강제종료 → 6시간 뒤 재실행: 상태가 경과만큼 진행, 문구·비주얼 정합(즉시 스냅 — 재생 애니메이션 없음)
- [ ] 기기 시계 하루 **뒤로**: 크래시 0, 전 타임스탬프 재정박(나이·단계 퇴행 없음), 알림 재예약
- [ ] 기기 시계 하루 **앞으로**: 정직한 catch-up (배고픔/시큼 진행)
- [ ] 10일 방치 시뮬(시계 조작): 휴면 도달(아직 곰팡이 아님), 부활 의식 2세션 완주 → 활발 복귀, maturity 보존.
  **14일(336h)은 곰팡이 사망 임계와 겹침 — G절에서 별도 검증**
- [ ] 급여 연타: maturity 미적립(유효 6h 게이트), mass·산미 정상, 착취 불가

## B. 저장

## C. 알림 (에뮬 + 실기기)

- [ ] 활발 상태에서 액션 직후 **슬롯 3개(밥·휴면·moldWarn) 전부 예약** 확인(`adb shell dumpsys notification`)
- [ ] 밥 직후 슬롯 1 예약 확인 → 시각에 수신 → 탭하면 앱 홈
- [ ] 냉장 이동 → 슬롯 1이 주간 반복 예약으로 전환, 앱 미실행에도 다음 주 발화. **moldWarn(슬롯 3)은 미포함** 확인

- [ ] **곰팡이 사망 후 알림 0건**(사망 시점·사망 후 통지 없음 — G절 사망 시나리오와 함께 확인)

- [ ] 권한 거부 상태에서 전 기능 정상
- [ ] **권한 영구 거부(2회 거부) → 설정 화면 안내 + openSettings 딥링크 왕복**

- [ ] Doze/절전에서 inexact 지연 체감 — 문구("쯤")와 어긋나지 않는지

### 알림 확장 (2026-09-03 — GDD §7 개정: 슬롯 4→7, 하루 상한 강제, 탭 딥링크, 설정 하위 모달)

- [ ] 실온 활발 새 게임(0단계): 예약에 **밥·휴면·곰팡이 + 피크(기본 on) + 시큼 + 첫 주(D2)** — 단 같은 날 2건 초과분은 우선순위대로
  빠져 있는지(`dumpsys notification`으로 id 1~7 확인). 밥 D1 · 시큼 D2 · 휴면 D5 · 곰팡이 D7 순
- [ ] 사이클은 채웠는데 일수만 남은 르방(개발자 만렙 뒤 새 르방 + 밥 연타): 성장 슬롯(id 6)이 `createdAt + 요구일`에 예약되는지
- [ ] 냉장·휴면·부활 중엔 시큼·성장·첫 주 슬롯이 **없는지**
- [ ] 설정 → `알림` 행 → 하위 모달: 마스터 + 항목 4개 + 방해 없는 시간 + (권한 거부 시) 안내 행. 마스터 off면 항목이 `.is-locked`이고
  탭하면 `알림 받기를 먼저 켜 주세요`
- [ ] 알림 탭 딥링크: 밥 알림 탭 → 앱이 홈으로 열리고 **밥 모달이 바로 뜨는지** / 피크 알림 탭 → 레시피 탭 / 콜드 스타트에 브리핑이
  먼저 뜨면 닫힌 뒤 밥 모달
- [ ] 알림 본문에 르방 이름이 보이는지(이름 없는 르방은 본문 없음)
- [ ] 관찰 카드 **말려두기**가 잠긴 상태(휴면·시큼 등 `phase≠active`, 또는 mass < 80g — 급여 직후 활발·양 충분이면 잠기지 않는 게 정상)에서
  눌리고 이유 토스트가 뜨는지(`disabled`였던 결함 — 무반응이면 회귀)

### 물성 축 분해 · 유리 접촉 (2026-08-25)

`scripts/motionlab-shot.mjs --all <dir>`로 8프리셋 일괄 촬영 후 육안. 셰이더 컴파일 실패는 이 스크립트가 잡는다.

- [ ] **피크에서 반죽이 유리에 눌려 있는가** — 공처럼 뭉쳐 유리에서 떨어지면 실패(구 동작)
- [ ] **갓 밥준이 되직해 보이는가** — 묽은 배터로 읽히면 실패. 잡아 늘였다 놓으면 안 튕기고 자국이 남는다
- [ ] 유리벽에 기공 필드가 보이는가(피크·상승에서 가장 진하게), **세로 홈은 없는가**
- [ ] 어두운 원형 함몰·밀집 점 클러스터 0 (트라이포포비아 규칙 §2 — 밝은 볼록 돔만)
- [ ] 피크 정수리가 **잘게 부서진 크러스트**인가 — 소프트아이스크림 꼭지 하나면 실패
- [ ] 광택 순서: 피크 > 상승 > 갓 밥준 (갓 밥준은 무광이 정상 — 실사진 정합)
- [ ] 하강·배고픔·시큼에서 **최고 수위 자국이 현재 수면보다 위에** 보이는가
- [ ] 휴면·곰팡이에서 유리벽 기공이 0인가 (죽은 분기 게이트)
- [ ] 젓고 떼었을 때 전신 출렁임이 **2회 안쪽**에서 멎는가 (구 동작은 5~6회 = 물)

### 선반 · 집 기준 굽기 · 타이포 재검수 (2026-09-05 — GDD §5·§6-2·§6-3, VISUAL §7-2. 플랜 modular-coalescing-tower)

- [ ] **르방 전환과 무관한 도감**: 성숙 르방 A + 갓 태어난 B, 통 320g. B를 활성으로 두고 레시피 탭 → 10장 전부 A 기준으로 **열려 있는지**,
  상태 줄이 `르방이 2 · 지금 굽기 좋아요`가 아니라 `보관 320g · 발효력 … · …`인지, 전환해도 `just-unlocked` 와이프가 재생되지 않는지
- [ ] **무료 빵 우회 회귀**(Opus 반론 FM1): B(0단계) 활성 + 집 4단계 + 통 20g → 깜빠뉴 `굽기` → `보관해둔 르방이 100g 필요해요` 토스트, 통 20g 그대로
- [ ] **통 품질 = 뗀 순간**: A를 피크(밥 후 5h)에 떼기 → 플랫브레드 best / A를 배고픔(밥 후 15h)에 떼기 → flat. 떼어내기 확인 모달 첫 문장이
  `한창 부풀어 있어요. 좋은 반죽이에요` / `많이 지쳤어요 …`로 갈리는지
- [ ] **빵에 맞는 반죽부터**: 배고픔 로트 100g + 피크 로트 200g → 플랫브레드(30g)는 피크 로트에서 나가 best, 피크 로트를 다 쓰면 다음이 flat —
  시트 `반죽` 행이 굽기 전마다 바뀌는지, 상태 줄(전체 평균)과 시트 `반죽` 행(이 빵에 골라 쓸 로트)이 **다를 수 있음**을 확인.
  산미 50 로트 + 산미 10 로트 → 호밀빵 시트 `반죽` 행이 `시큼` 쪽(산미 50 로트)을 가리키는지
- [ ] **곰팡이 뒤 레시피 유지**(2026-09-05 설계 변경): 유일한 르방이 곰팡이 → 새 반죽으로 시작 → 레시피 카드가 잠기지 **않고**, 통에 남은 g만큼 굽기 가능
- [ ] 1.4.0 저장본 업그레이드: 로트 없는 `pantry: 320` → 첫 진입에 상태 줄 `발효력 좋음 · 순함`(레거시 0.8/25), 선호 범위 안 빵 best
- [ ] **선반**: 세그 `[빵 | 선반 | 재료]`, 재탭 순환 3단, 힌트 문구 `한 번 더 누르면 선반과 재료로 넘어가요` 첫 3회. 선반 = 구운 것만 **빵 종류별 묶음**
  (묶음 머리 = 빵 이름, 묶음 순서 = 카탈로그 순, 묶음 안은 기본 빵 → 변형이 시트 칩과 같은 순서. 최근 구운 순 아님 — 2026-09-05 개정),
  변형 타일에 **베이스 PNG + 재료 아트**가 겹쳐 보이는지(＋ 원 SVG 플레이스홀더 0건), 전용 PNG 4종(초코칩 스콘 등)은 배지 없이 전용 그림.
  빈 선반 문구. 타일 탭 → 결과 카드(아트 크게 + 정보 행) → `3D로 보기`(GLB 없으면 카드로 복귀) / `다시 만들기` → 그 변형이 선택된 시트
- [ ] **시트 머리**: 아트 가운데, 정보 행 `필요 / 보관(모자라면 값 아래 …모자라요) / 반죽 / 가루(호밀·통밀 우세일 때만) / 최고 / 횟수 / 변형` —
  ` · `로 이어진 문장이 **한 줄도 없는지**. 미보유 칩에 `0` pill 없음, `아직 없는 재료` 구분선 아래 옅게
- [ ] **재료 탭 = 4열 칩**: 밝혀짐 또렷+수량 / 미발견 `?` 칩(이름 없음). 2열 대형 `?` 카드 0건
- [ ] **타이포 게이트**(390×844·360×800, `scratchpad/ui/shots.mjs` 방식): 13px 미만 글자 0(12px는 숫자 pill만) · ellipsis 잘림 0 ·
  **`scrollWidth > clientWidth` 넘침 0**(해바라기씨·피스타치오 칩) · 구 중간 줄바꿈 0 · 같은 행 카드 높이 편차 0 · 대비 4.5:1 미만 본문 0.
  긴 이름 픽스처: `초코 필링 팬케이크`·`동결건조 블루베리 깜빠뉴`(선반 타일 2줄)
- [ ] **실기기 글자 배율 1.3×·2×**: 칩 이름 2줄 안에 드는지, 세그 3개 라벨이 한 줄인지, 정보 행 값이 라벨을 밀지 않는지(브라우저로는 근사 불가)
- [ ] 롤백 리허설(RELEASE §8): 1.5.0 저장본을 1.4.0 번들로 열면 통 g은 그대로·등급은 활성 르방 기준으로 복귀, 다시 1.5.0으로 올리면 레거시 로트로 재물질화, 세이브 손실 0
