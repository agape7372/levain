# 르방이 — 수동 QA 체크리스트 (릴리스 게이트)

전제: vitest 전 suite green. 아래는 실기기/에뮬 수동 검증. 판정이 애매한 항목은 본 세션 재확인.

## A. 시간·시뮬레이션

- [ ] 강제종료 → 6시간 뒤 재실행: 상태가 경과만큼 진행, 문구·비주얼 정합(즉시 스냅 — 재생 애니메이션 없음)
- [ ] 기기 시계 하루 **뒤로**: 크래시 0, 전 타임스탬프 재정박(나이·단계 퇴행 없음), 알림 재예약
- [ ] 기기 시계 하루 **앞으로**: 정직한 catch-up (배고픔/시큼 진행)
- [ ] 10일 방치 시뮬(시계 조작): 휴면 도달(아직 곰팡이 아님), 부활 의식 2세션 완주 → 활발 복귀, maturity 보존.
  **14일(336h)은 곰팡이 사망 임계와 겹침 — G절에서 별도 검증**
- [ ] 급여 연타: maturity 미적립(유효 6h 게이트), mass·산미 정상, 착취 불가

## B. 저장

- [ ] 새로고침·강제종료 후 상태 보존 (액션 직후 동기 저장)
- [ ] 주 슬롯에 쓰레기 문자열 주입 → Preferences 미러 폴백 / 둘 다 손상 → 새 게임 + 담백한 안내
- [ ] NaN·범위 밖 값 주입 → clamp 회수(새 게임으로 안 튐)
- [ ] 설정 "기록 내보내기" → 파일 → "불러오기" 왕복 일치
- [ ] **앱 재설치 → Auto Backup 복원 상태 확인** (allowBackup — 복원되면 보너스, 안 되면 내보내기 안내가 정본)
- [ ] 굽기 연출 중 강제종료 → 재실행 시 pendingBake 결과 카드 재노출, 확인 연타에도 중복 기록 0

## C. 알림 (에뮬 + 실기기)

- [ ] 활발 상태에서 액션 직후 **슬롯 3개(밥·휴면·moldWarn) 전부 예약** 확인(`adb shell dumpsys notification`)
- [ ] 밥 직후 슬롯 1 예약 확인 → 시각에 수신 → 탭하면 앱 홈
- [ ] 냉장 이동 → 슬롯 1이 주간 반복 예약으로 전환, 앱 미실행에도 다음 주 발화. **moldWarn(슬롯 3)은 미포함** 확인
- [ ] 휴면 진입 후 moldWarn(슬롯 3) 1건만 남고 나머지 침묵 / reviveProgress=1이면 슬롯 1을 +8h로 재예약
- [ ] **곰팡이 사망 후 알림 0건**(사망 시점·사망 후 통지 없음 — G절 사망 시나리오와 함께 확인)
- [ ] 조용시간(22~08) 걸리면 다음 08:00으로 클램프
- [ ] 권한 거부 상태에서 전 기능 정상
- [ ] **권한 영구 거부(2회 거부) → 설정 화면 안내 + openSettings 딥링크 왕복**
- [ ] 기기 재부팅 → 예약 알림 생존(또는 resume 재예약으로 커버) 판정
- [ ] Doze/절전에서 inexact 지연 체감 — 문구("쯤")와 어긋나지 않는지
- [ ] manifest에 SCHEDULE_EXACT_ALARM/USE_EXACT_ALARM 없음 확인 (`aapt dump permissions`)

## D. Android 내비게이션·시스템

- [ ] **하드웨어 백 전수**: 모달 열림→닫힘 / 레시피→홈 / 굽기 연출 중→스킵 / 루트→minimizeApp(종료 아님)
- [ ] Android 14+ predictive back에서 이상 동작 없음
- [ ] 세로 고정, 회전 시도에도 레이아웃 불변
- [ ] 상태바: 베이지 배경 위 **어두운 아이콘**, 펀치홀·엣지투엣지(targetSdk 35)에서 상단 HUD 안 가림
- [ ] 스플래시 단색 #E8D9C4 → 첫 화면 연속성(플래시 없음)
- [ ] OS 폰트 스케일 200%: 레이아웃 깨짐·잘림 없음
- [ ] 키보드(내보내기 파일명 등 입력 시) 겹침 없음

## E. 렌더·성능

- [ ] 레시피 탭↔홈 왕복: rAF 정지/재개 (GPU 프로파일로 확인)
- [ ] hidden(홈버튼) → rAF·오디오 정지, 복귀 → uTime 연속성(점프 없음)
- [ ] WebGL 컨텍스트 유실 강제(`WEBGL_lose_context`) → 자동 전체 재구축, 상태 보존
- [ ] 저사양 프로필(에뮬 swiftshader)에서 인터랙션 중 프레임 급락 없음
- [ ] draw call ≤ 10 확인(Spector.js 또는 renderer.info) — 홈 9(천 덮개 포함) / **쇼케이스 진입 시 별도 ≤4**
- [ ] DPR 2 기기에서 발열·배터리 이상 없음 (10분 방치)

## F. 콘텐츠·UI

- [ ] 온보딩(창조 의식) 완주 → 재실행 시 스킵
- [ ] 성장 단계 0→2 압축 시뮬(시계 조작): D2 가짜 부풀기 이벤트, 잠잠기 억제, 첫 해금 토스트
- [ ] 레시피 탭: 첫날부터 실루엣 도감(빈 탭 아님), 해금 조건 문구, 해금 시 wipe 연출
- [ ] 레시피 그리드: 썸네일(`public/breads/thumbs/`) 미생성 빵은 breadArt 폴백 렌더 확인
- [ ] 띄워보기: activity 경계(0.7)에서 문구 전환
- [ ] 굽기: mass 게이트(비용+60g 미달 시 진입 불가 + 담백한 안내), 등급 3종 각각 재현
- [ ] 호밀빵: 시큼 상태(산미 40~75)에서 고득점 확인
- [ ] **전 모달 중앙 팝업**(바닥 시트 0건), 전 문구 시스템어 0건 (copy.ts 전수 대조)
- [ ] 사운드 5종 재생·음소거 토글, 첫 제스처 전 무음(콘솔 경고 0)
- [ ] 햅틱 3종 발화, 설정 오프 시 전부 무진동

## G. 신규 시스템 (곰팡이·플레이크·브리핑·천 덮개·촉감·쇼케이스)

**QA 노트**: 반점(168h)·확산(240h)·사망(336h) 임계는 시계 조작만으로 정밀 재현이 어려우므로
`levain:save`의 `sim.lastFedAt`을 직접 조작(현재시각 − 170h / − 250h / − 340h)한 뒤 새로고침으로 재현한다.

- [ ] `lastFedAt` −170h → 관찰 카드 '표면' 행에 반점 표시 + 데드라인 문구, moldWarn 알림 예약 확인
- [ ] −250h → 확산 표시로 갱신 / −340h → **곰팡이 사망 모달 자동 노출**(앱 열 때마다 재노출)
- [ ] **사망 후 (a) 플레이크 有** → "말린 조각으로 다시 시작" → maturity 0.6배 축소 → 12h 경과(저장 조작) →
  2회차 급여 → revived·활발 복귀
- [ ] **사망 후 (b) 플레이크 無** → "새 반죽으로 시작" → 새 개체(maturity 0, label 초기화), 도감 보존 확인
- [ ] 말리기 버튼: 3단계 미만 숨김 / 3단계 이상 & phase≠활발 비활성 / 3단계·활발·mass≥80 → 확인 모달 →
  성공 시 mass −20g + 관찰 카드 '보관' 행 갱신
- [ ] 복귀 브리핑: 부재 8h 이상 후 열기 → "그동안 있었던 일" 시간순 모달 / 8h 미만은 안 뜸
- [ ] 천 덮개: 콜드 스타트·hidden 30분+ 복귀 시 덮인 상태로 시작, 위 플릭/탭 → 걷기 + 사락 + 밀가루 모트,
  덮인 동안 poke·젓기 무시
- [ ] 젓기 촉감: 드래그 → 소용돌이 시어장 + 끈적한 실 능선 + 기포 가속 + squelch, 손 떼면 spring 복귀,
  **세션(down~up)당 햅틱 최대 1회**
- [ ] 탭(poke): 가우시안 덴트 펄스 + spring 복귀 + 근처 기포 유도 / 롱프레스(0.8s+): 표면이 천천히 부풂, 떼면 easeOut
- [ ] 쇼케이스: 굽기 결과 — GLB 있는 빵은 턴테이블+드래그 회전+김 파티클, 백 버튼 → 홈 복원 /
  GLB 없는 빵은 기존 카드 결과로 폴백
