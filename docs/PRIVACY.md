# 르방이 개인정보처리방침

시행일: 2026-08-23
개정: 2026-08-30 (보상형 광고 도입 — Google AdMob)

## 기록은 기기 안에만

게임의 모든 기록(르방 상태, 구운 빵 도감, 설정)은 사용자의 기기 안에만 저장됩니다. 저희(개발자)는
이 기록을 서버로 전송받지 않으며, 볼 수도 없습니다.

- 앱을 열 때 새 버전이 있는지 확인하기 위해 업데이트 파일 주소에 접속합니다. 이때 게임 기록은
  전송되지 않으며, 확인하는 것은 버전 번호뿐입니다. 다만 일반적인 인터넷 접속과 마찬가지로 기기의 IP 주소가
  접속 기록으로 남을 수 있습니다.
- 알림은 기기 내 로컬 알림만 사용합니다 (밥 시간 안내).
- "기록 내보내기"는 사용자가 직접 실행할 때만 기기 내 파일로 저장되며, 공유 여부는 전적으로 사용자가 결정합니다.
- 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.
- 분석 도구, 사용자 행태 추적 SDK는 사용하지 않습니다.

## 보상형 광고 (Google AdMob)

원하는 사용자만 짧은 영상 광고를 보고 게임 내 재료를 받을 수 있는 기능이 있습니다. **모든 광고는
사용자가 직접 버튼을 눌러야만 재생되며, 앱을 열거나 사용하는 동안 저절로 뜨는 광고는 없습니다.**

이 기능을 위해 Google AdMob(광고 SDK)을 사용하며, 광고가 재생될 때 Google이 광고 식별자(기기의
광고 ID) 등 일부 정보를 처리할 수 있습니다. 저희는 이 정보를 직접 수집하거나 저장하지 않으며,
Google의 처리 방식은 아래 링크에서 확인할 수 있습니다.

- Google의 개인정보처리방침: https://policies.google.com/privacy
- 광고 개인화 설정은 기기의 [설정 → 광고]에서 광고 ID 재설정 또는 관심 기반 광고 선택 해제로
  조정할 수 있습니다.
- 유럽경제지역(EEA)·영국 사용자에게는 최초 실행 시 Google의 동의 관리(UMP) 절차가 표시되며,
  이후에도 설정 화면에서 동의 항목을 다시 확인할 수 있습니다.
- 만 14세 미만 아동을 대상으로 하지 않으며, 아동 대상 광고 제한이 적용됩니다.
