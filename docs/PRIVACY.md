# 르방이 개인정보처리방침

시행일: 2026-08-23

**르방이는 어떤 개인정보도 수집하지 않습니다.**

- 게임의 모든 기록(르방 상태, 구운 빵 도감, 설정)은 사용자의 기기 안에만 저장됩니다.
- 서버가 없으며, 어떤 데이터도 외부로 전송되지 않습니다.
- 광고, 분석 도구, 제3자 SDK를 사용하지 않습니다.
- 알림은 기기 내 로컬 알림만 사용합니다 (밥 시간 안내).
- "기록 내보내기"는 사용자가 직접 실행할 때만 기기 내 파일로 저장되며, 공유 여부는 전적으로 사용자가 결정합니다.
- 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.
