## Decisions Made

| Decision | Options | Rationale |
|---|---|---|
| 보관 통을 **오브젝트로 승격**(버튼 이동 아님) | 버튼만 옮김 / 오브젝트화 | 버튼만 옮기면 잔량칩·힌트가 남아 셋째 행이 안 사라진다 = 밀집 그대로 |
| **DOM 오버레이**(3D 아님) | 씬에 두 번째 병 / DOM | 프러스텀 반폭 1.33에 천 덮개 1.17 — 여유 0.16 world unit. 게다가 히트테스트가 평면 근사라 탭 오브젝트 선례 0건이고, 제스처 FSM을 그날 막 안정화했다 |
| 수위 스케일 = `MASS_MAX` | 임의 상한 / MASS_MAX | 지금 보고 있는 그 병의 용량 → **새 매직넘버 0**. 1:1:1 한 판이 정확히 25% |
| 숫자 대신 수위 | g 표기 병기 / 수위만 | g이 답하는 질문은 레시피 화면이 이미 정확히 답한다. 40px 병에 10px 숫자는 캡션 하한(13px) 위반 |
| 뚜껑만 비활성, **몸통은 또렷** | 전체 비활성 / 분리 | `canSplit`이 6h 게이트라 자주 false인데 그때마다 재고 표시까지 죽으면 안 된다 |
| 타임라인 **축 = 유효시간** | wall-clock / 유효시간 | wall-clock이면 냉장 이동 때 점이 35.7%→4.3%로 뒤로 점프 = 거짓말 |
| 밴드는 `RATIOS` 직접 | `peakAt/peakEndAt` / RATIOS | 아래 Gotchas 참조 — 클램프로 붕괴한다 |
| 말려두기 → 관찰 카드 | 하단 잔류 / 관찰 카드 | 고아 행을 안 만든다. 카드는 "잃을 수도 있다"를 말하는 유일한 화면이고 말려두기는 유일한 응답 |

## Blockers/Open Questions

- [ ] **"한창 부풀어 있어요"와 밴드의 정의가 다르다.** 문구는 `activity ≥ 0.85`(1:1:1에서 유효
      3.33~8.14h), 밴드는 `peakStart~peakEnd`(4.5~6h). 문구가 "한창"인데 점은 밴드를 지나 있을 수 있다.
      맞추면 "한창" 노출이 사이클의 34% → 11%로 줄어든다 — **수정이 아니라 제품 변경**이라 손대지 않았다.
- [ ] 관찰 카드의 "조작 1개 상한"은 문서로만 강제된다(테스트 없음).

## Potential Gotchas

- **`wallFor`의 클램프**: `locAnchorAt + Math.max(0, h*HOUR - effBaseMs) / mult`. `effBaseMs`가
  해당 경계를 넘으면 그 예측값이 `locAnchorAt`으로 **붕괴**한다. 그래서 피크가 지난 뒤 위치를 바꾸면
  `peakAt === peakEndAt`이 되어 밴드 폭이 0이 된다 — 타임라인이 `RATIOS`를 직접 읽는 이유.
- **absolute HUD 컨테이너는 보이지 않는 곳에서 입력을 삼킨다.** `.hud-top`이 `left/right` 절대배치라
  358×96 박스 전체가 `.screen--overlay > *`의 `pointer-events:auto`를 받아 왔다(빈 여백까지).
  **규약: 컨테이너 `none` + 실제로 눌러야 하는 자식만 `auto`.** `.hud-corner`도 같다.
- **`background-size` 목록과 `background-image` 레이어 수가 어긋나면 전환이 조용히 죽는다.**
  병 수위가 그 구조다 — 층을 더하거나 뺄 땐 둘을 함께 고칠 것.
- **색 대비는 눈으로 판단하지 말 것.** 수위 빈 쪽을 `bg-soft 62%`로 뒀더니 크림과 대비 1.03이라
  10%든 100%든 픽셀이 같았다(기능이 죽어 있었다). 어둡게 바꿔 1.52. QA 픽셀 스캔이 잡았다.
- **점에 위치 트윈을 넣지 말 것** — 이 레포는 "경과를 애니메이션으로 재생하지 않는다"가 계약이다.
  재개·르방 전환에서 점이 축을 가로지르면 그게 곧 경과 재생이다.
- 병에 눈금·게이지를 붙이는 설계는 금지(VISUAL §1-2, 사용자 확정 폐기). 타임라인이 그 부활로 보이지
  않는 이유는 §7-3에 대조표로 박아 뒀다.
