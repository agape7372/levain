## Architecture Overview

굽기의 그램 원가가 **르방이 개별 `mass` → 집(전역) 소유 `shared.pantry`** 로 이동했다.
이음새 한 줄: `split 액션(sim, mass→씨앗) → split 이벤트 → store.applyPantryEvents(통 적립)`
그리고 `bake(sim, 판정만) → baked 이벤트 → store.applyPantryEvents(통 차감)`.

계층은 **비대칭이고 그게 정답이다**:

| 액션 | 게이트 대상 | 게이트 위치 |
|---|---|---|
| 떼어내기 `split` | 자기 `mass`, 유효시간 | **sim** (`actions.ts`) — sim이 아는 값 |
| 굽기 `bake` | 전역 통 잔량 | **store** (`gameStore.pantryGate`) — sim은 전역을 모른다 |

## Decisions Made

| Decision | Options | Rationale |
|---|---|---|
| 떼기 게이트 = **유효 6h** | `phase==='active'` / 급여당 1회 / 유효시간 | active는 **단조가 아니라** 피크 놓친 플레이어가 회수를 못 한다 = 고치려던 문제 재생산. "급여당 1회"는 급여에 쿨다운이 없어 연타가 그대로 뚫린다 |
| 통 게이트를 `doDispatch`에 | `bakeVariant` 내부 / `doDispatch` | UI가 베이스 빵을 `dispatch({type:'bake'})`로 직접 쏴서 `bakeVariant`를 우회한다 |
| **스키마 버전 유지(v2)** | v3 승격 / 무버전 추가 키 | `migrate`가 미래 버전을 `null`(=새 게임)로 떨군다 → 올리면 **부팅 크래시 시 OTA 자동 롤백이 저장본 전멸**. flour·inventory·economy가 같은 선례 |
| 마이그레이션 선물 없음 | `Σ(mass−SEED_G)` 적립 / 0 | `mass`가 곧 "아직 안 뗀 예치금" — 떼기 한 번이면 들어온다 |
| 통에 품질 안 담음 | 가중평균 스냅샷 / 순수 g | 섞으면 "나쁠 때 떼면 평균이 내려간다"는 역인센티브. 피크 굽기 재미도 그대로 보존 |
| 부분 인출 없음(한 방) | 슬라이더 / `mass − SEED_G` | 남긴 몫은 다음 급여 리셋에 증발 → 슬라이더가 함정이 된다. **사용자가 고른 선택지 설명("원하는 만큼")과의 의도적 이탈** |
| 재료 SVG 유지 | 즉시 제거 / 임시 유지 | 지금 걷어내면 도감·재료함이 빈칸. 그록 이미지 도착이 교체 타이밍 |

## Potential Gotchas

- **`renderParams.ts`는 `mass`를 참조하지 않는다.** 질량 변화의 시각 반응은 `derive.ts`의
  `fill` 질량비 한 줄이 전부다. 여기를 지우면 떼어내도 병이 그대로다.
- **`derive.canSplit`과 `actions.split`의 게이트 식은 손으로 맞춘 쌍이다.** 어긋나면
  "눌리는데 막히는 버튼"이 된다. `tests/pantry.test.ts`가 세 상태로 교차 검증한다.
- **`devMatureActive`는 `lastFedAt`을 안 건드린다** → 유효시간 0이라 떼기가 막힌다.
  테스트·QA에서 떼기 상태가 필요하면 envelope를 직접 구성하거나 시계를 돌려라.
- **vitest는 node 환경**(jsdom 없음). DOM 테스트는 스텁으로 짠다. rAF 스텁은 **0을 돌려줘야**
  한다 — 실제 핸들을 주면 `processMove`가 비운 `rafId`를 호출부가 도로 채워 두 번째 move부터
  영영 스케줄되지 않는다.
- **`npx eslint .`는 `android/app/build/` 생성물에서 2건 뜬다.** 우리 코드와 무관하고 그 디렉터리가
  존재할 때만 난다. 실제 게이트는 `npx eslint src tests`.
- **`ingredients.ts` 실제 카운트**: 재료 12 · **형태 21**(20 아님) · COMPATIBILITY 89행 · v1 노출 72.
- OTA `bundles/`는 커밋 제외 — 로컬에 1.2.2/1.2.3/1.2.4/1.3.0만 남아 있다(상한 4개).
