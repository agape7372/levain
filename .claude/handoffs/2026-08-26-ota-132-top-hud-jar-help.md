## 함정 (다음 세션이 반드시 볼 것)

1. **`style.cssText`의 `font:inherit`가 CSS 규칙을 통째로 죽인다.**
   `home.ts:31`에 있던 버튼 리셋 때문에 `.hud-status{font-size:17px;font-weight:600;color:var(--ink)}`가
   **한 번도 적용된 적이 없었다** — 실렌더 16px/400/`--ink-soft`. 인라인이 작성자 규칙을 이기고
   `font:inherit`는 sub-property 전부를 상속으로 리셋한다. 타입·린트·테스트 전부 못 잡는다.
   **검증법 = `getComputedStyle`로 실렌더 값을 읽어라.** CSS만 고치면 "고쳤는데 기기에선 그대로"가 된다.
   `.hud-status`에 되돌림 방지 주석을 박아 뒀다 — 인라인 style을 되살리지 말 것.
2. **UA 스타일시트 2종이 왼쪽 정렬에서만 드러난다.**
   `button{padding:1px 6px}`(제목이 6px 들여쓰기) · `button{text-align:center}`(**상속을 이긴다** —
   한 줄일 땐 안 보이지만 200% 배율에서 제목이 줄바꿈되면 2·3행만 가운데로 선다). 둘 다 명시 제거·명시 지정.
3. **알약 배경을 빼면 `padding`도 같이 빼야 한다.** `.hud-stage-chip`의 `padding:3px 10px`을
   남기면 머리글만 10px 들여쓰기된다. 같은 맥락에서 `transform-origin: left center`도 필요 —
   `chip-pulse`의 `scale(1.06)`이 가운데 정렬에선 안 보였지만 왼쪽 정렬에선 시작선을 5.7px 민다.
4. **오버레이를 옮길 땐 형제 컬럼 높이까지 피해야 한다.** 토스트를 `var(--hud-top-h)`만 피하게 했더니
   문장 1줄 상태(105px)에서 토스트 상단 133 vs **항아리 바닥 132 = 1px**.
   오른쪽 코너가 더 길다(`? ⚙` 38 + gap 10 + 항아리 70 = 118) → `max(var(--hud-top-h,120px), 118px)`.
5. **`npx eslint tests`는 현재 config가 `tests/`를 무시한다.** 실제 게이트는 `npx eslint src`뿐.
   (`npx eslint .`는 `android/app/build/` 생성물에서 2건 뜨니 판정 기준 아님 — 기존 함정.)
6. 토스트 캡처 자동화: 클릭 → 별도 MCP 호출로 스크린샷은 **왕복 지연이 토스트 수명(2.9s)을 넘겨** 빈 화면이
   찍힌다. `window.setTimeout`을 no-op으로 스텁하면 자동 소멸이 안 걸려 안정적으로 잡힌다(등장은 rAF 구동이라 무영향).
