## ★근본 원인 두 가지

### 1. 면이 뒤집혀 있었다 (fig · beet · pumpkin)

셋 다 로컬 셸 빌더가 lib의 `buildRevolvedShell`과 **거울상 좌표계**(`z=-sin` 또는 `x=sin/z=cos`)를
쓰면서 인덱스 감기는 lib 것을 그대로 복사했다. 손잡이가 뒤집혀 법선이 전부 안을 향했다.

런타임은 `MeshLambertMaterial` 기본 FrontSide라 **가까운 벽이 컬링돼 사라진다** —
일부 각도에서 몸통이 통째로 없어지고 꼭지만 남아 **"떠 있는 꼭지"**로 보였다.
(사용자가 스크린샷으로 지적한 비트·무화과가 정확히 이것이다.)

실측: 바깥향 삼각형 **5~8% → 98~100%**, 부호부피 음수 → 양수.

★**기존 게이트가 전부 이걸 통과시켰다** — tri·KB 예산 · mesh≤2 · GLB 왕복 파리티 · 64px 판독.
뒤집힌 셸은 삼각형 수도 파일 크기도 정상이고 썸네일 각도에서는 멀쩡해 보였다.
**수치가 맞다는 것과 면이 바깥을 향한다는 것은 별개다.**

### 2. 예산을 잘못 잡았다

재료 예산이 빵의 1/4이었다(100KB/2500tri vs 250KB/8000tri). 조인 근거가 "재료는 더 단순하다"였는데
**진짜 이유는 도감 썸네일이 작아서**였고, 재료도 빵과 **똑같은 쇼케이스에서 똑같은 크기로 확대돼**
**감상된다**는 걸 계산에 안 넣었다(`src/render/breadShowcase.ts`의 `FIT_SIZE = 1.6`은 패밀리를 안 가린다).

64px에서는 멀쩡하고 전체 화면에서는 각지고 조잡했다. **빵과 같게 상향했다**(250KB/8000tri, 합계 160KB/개).

## 재개 지점 — 파손 2건부터

중단된 워크플로가 이 둘을 고치던 중이었다. **처방은 이미 확정돼 있다.**

### `honey` — 꿀 드립이 공중부양으로 읽힌다

실루엣상 벌집과 붙어 있다(분리섬 1개). **떨어져 있는 게 아니라 떠 있는 것으로 보인다**가 정확하다.

- **180°(최악)**: 돔+퍼들이 벌집 **왼쪽 바깥 허공**에 나와 있고 아래로 배경이 비친다
- **270°**: 얇은 주황 원반이 상판 위 부유하는 동전
- **90°**: 원통 아래 접시가 달린 **압정/버섯** 꼴, 접시 아래 전부 허공

★원인: 바닥면 없이 **지면 전제의 납작한 퍼들 원반**을 놓았다.
★**레퍼런스(`assets/ingredients/src/honey.png`)에는 지면 퍼들이 아예 없다** — 작고 뭉친 꿀 덩어리가
벌집 모서리 **위에** 얹혀 있을 뿐이다. **퍼들을 없애고 레퍼런스대로 가는 게 가장 확실하다.**
셀 격자는 건드리지 마라 — 직전 수리에서 맞닿는 지그재그로 고쳐 벌집으로 읽히게 된 부분이다.

### `flaxseed` — 공 모양 더미를 칼날이 관통한 것처럼 보인다

- **az≈195~225**: 뒤쪽 낱알이 스침각으로 들어와 납작 씨앗이 종잇장이 된다 —
  225에서 **단검**+**날개**가 동시에 보인다. (같은 메커니즘인 `poppyseed`는 알갱이가 구체라
  "뜬 구슬"로만 보여 약함 — **flaxseed는 납작해서 칼날이 된다.** 판정이 갈리는 지점.)
- **az=0·150·270**: 실루엣에 얇은 **지느러미 슬리버**
- 레퍼런스는 **넓고 납작한 비늘 더미**인데 렌더는 정구형 → 트러플·아티초크로 읽힘

처방: 채움 돔이 반지름 0.50 / 반높이 0.30으로 높이:폭 ≈1:1 → **`FILL_HALF_HEIGHT`를 내려 낮고 넓게.**
낱알 견본이 **뒤로 안 돌게** 배치. **낱알을 지우는 게 아니다**(지우면 정체가 사라진다).

## 함정 (다음 사람이 밟을 것)

1. ★**세그먼트를 올리면 지터 진폭도 같이 내려라.** 지터가 극 근처 링의 컬럼 간격(≈π·r/segments)을
   넘으면 극 팬 삼각형이 뒤집힌다. 실측: fig 안쪽향 17장 → amp 0.017→0.011에서 2장, pumpkin 7 → 0.
2. **각도차 접기에 `% 2π`가 빠지는 버그가 두 파일에 있었다**(`fig`·`sweetpotato`).
   `atan2`는 (-π,π]인데 각도 배열이 [0,2π)라 `d = 2π - d`가 **음수**가 되고 조건이 무조건 참이 된다.
   → 텍스처 절반이 통째로 한 색으로 칠해진다. 다른 파일에도 있는지 봐라.
3. **`CanvasTexture`는 기본 `flipY=true`** — `v = py/size`를 그대로 쓰면 세로로 뒤집혀 붙는다.
4. **서브에이전트가 도는 중에 `git stash`를 돌리지 마라.** 이번에 한 번 했고 운 좋게 유실이 없었다.
5. **`bake-thumbs.mjs`는 id 필터가 없는 디렉터리 글롭**이다. 병렬 수리 중에 돌리면 서로 덮어쓴다 —
   **마지막에 한 번** `npm run ingredients:thumbs`.
6. `rmSync(dir,{recursive,force})`가 이 환경에서 **에러 없이 실패**한다(앞 핸드오프 참조).
